# 상업용부동산 공실률 탭 설계

## 배경

사용자가 한국부동산원(R-ONE 부동산통계정보시스템) Open API 인증키를 제공하며
"상업용부동산 임대동향조사 (상가/공실률)" 기능 추가를 요청했다. R-ONE 포털에서
공식 개발가이드 문서(`기술문서_부동산통계 Open API 서비스_240905.docx`)를 내려받고,
제공된 키로 실제 호출을 검증해 API 구조를 확인했다.

## API 요약 (검증 완료)

Base: `https://www.reb.or.kr/r-one/openapi/`

- `SttsApiTbl.do?KEY=&STATBL_ID=` — 통계표 메타(주기코드, 시작/종료연도 등)
- `SttsApiTblItm.do?KEY=&STATBL_ID=&ITM_TAG=분류` — 상권/지역 분류코드(CLS_ID) 목록
- `SttsApiTblData.do?KEY=&STATBL_ID=&DTACYCLE_CD=QY&WRTTIME_IDTFR_ID=&CLS_ID=&START_WRTTIME=&END_WRTTIME=` — 실제 수치

분기(QY) 시점 포맷은 `YYYYQQ`(예: `202403` = 2024년 3분기, 2자리 분기 번호 필수).
공실률 통계표코드(2024년 3분기~ 최신, 유형별):

| 유형 | STATBL_ID |
|---|---|
| 오피스 | TT244763134428698 |
| 중대형 상가 | T249633134845544 |
| 소규모 상가 | T241833134686576 |
| 집합 상가 | T243283134931290 |
| 일반 상가 | T262303140824764 |

이전 시기(2022년~2024년 2분기)는 `A_2024_0025X` 계열의 **별도** 통계표코드를 쓴다.
두 표의 `STATBL_CMMT`에 "상권 재구획·표본재설계('24년2분기)로 시계열 해석에 유의"라고
명시되어 있어, 두 표의 CLS_ID가 같은 상권이라도 다르게 재구획되었을 수 있다 — 이 경계를
가로질러 자동으로 이어붙이면 데이터를 왜곡할 위험이 있다.

## 결정 사항

- **최신 표(2024년 3분기~)만 사용한다.** 과거 표(A_2024_0025X)는 연결하지 않는다 —
  재구획 경계를 자동으로 이어붙이면 오해를 부를 수 있어서다. 2024년 3분기 이후로도
  약 2년치 분기 데이터가 있어 추이를 보기에 충분하다.
- 사이드바에 "한국부동산원 인증키" 입력란(`reb_key`)을 기존 키 입력란과 같은 패턴
  (비밀번호 타입, 매 세션 수동 입력, 코드에 하드코딩하지 않음)으로 추가한다. 사용자가
  채팅으로 전달한 실제 키 값은 코드/커밋에 절대 남기지 않는다.
- 새 탭 "🏬 상업용부동산 공실률"을 추가한다. 표시 방식은 사용자가 선택한 대로 **표 +
  추이 그래프 둘 다** 보여준다.

## UI/데이터 흐름

1. 유형 선택(오피스/중대형 상가/소규모 상가/집합 상가/일반 상가) + 분기 선택
   (2024년 3분기 ~ 현재 분기 범위에서 최신 분기가 기본값; 최신 분기에 아직 데이터가
   없으면 데이터가 있는 가장 최근 분기까지 자동으로 한 분기씩 물러나며 탐색).
2. 해당 유형·분기의 전체 상권 공실률을 한 번의 `SttsApiTblData` 호출로 가져와
   공실률 내림차순 표로 표시. 상권명 검색창으로 필터링 가능 (예: "연남" 입력 시
   "서울>영등포신촌>동교/연남" 매치).
3. 표에서 상권을 선택(또는 검색 후 selectbox로 선택)하면, 해당 상권의 `CLS_ID`로
   `START_WRTTIME=202403&END_WRTTIME=<최신 분기>` 한 번의 호출로 전체 추이를 가져와
   `st.line_chart`로 분기별 공실률 추이를 표시.

## 에러 처리

- `reb_key` 미입력 시 안내 캡션만 표시하고 호출하지 않는다.
- API가 `ERROR-290`(키 오류)/`ERROR-300`(파라미터 누락) 등을 반환하면 원문 메시지를
  그대로 `st.error`에 노출한다 (다른 탭의 기존 에러 처리 패턴과 동일).
- 특정 분기에 데이터가 없으면(`INFO-200`) 표 대신 안내 문구를 보여준다.

## 범위 밖

- 임대가격지수·임대료·수익률 등 다른 통계는 이번에는 추가하지 않는다 (요청 범위인
  공실률만 구현).
- 과거 표(2022~2024Q2)와의 자동 연결은 하지 않는다 (위 결정 사항 참고).
